# 🩸 Hotel of Damnation
### A 2D Horror Platformer | Oslo: Climb for Survival

> *Escape the hotel. Outrun the nightmare. Reach the rooftop.*

## 📖 About the Game

In the middle of a monster outbreak, Oslo gets trapped in the basement of the hotel where he works. His only chance of survival is to climb his way to the rooftop, where a rescue helicopter awaits.

But escape won't be easy. As Oslo makes his way through the ruined hotel, a massive creature slowly rises from the depths, determined to make him its next meal.

With danger lurking in the darkness, every jump could be his last.

**Will Oslo escape the nightmare, or become the monster's next victim?**

## 🎮 Gameplay

*Oslo: Climb for Survival* is a 2D horror platformer developed with Unity. Players must navigate a dangerous hotel, overcome obstacles, and climb toward safety while escaping the horrors lurking below.

The game combines vertical platforming with horror elements, challenging players to react quickly, time their jumps, and survive the climb.

### Core Gameplay Elements

- **Vertical Platforming** — Jump between platforms and climb toward higher floors.
- **Double Jump** — Reach platforms that would otherwise be out of reach.
- **Horror Atmosphere** — Explore a ruined hotel overrun by monstrous growths and supernatural threats.
- **Survival Challenge** — Keep moving and avoid falling victim to the horrors below.

## 🚀 Getting Started

To explore the project locally:

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add project from disk** and choose the project folder.
4. Open the project using a compatible Unity Editor version.
5. Open the available scenes and run the game from the appropriate starting scene.

**Unity Version:** `6000.3.16f1`

> Allow Unity to import the project's assets and packages before running the game for the first time.
